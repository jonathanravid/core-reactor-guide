# CORE — How a Reactor Works

Interactive field guide to a nuclear reactor: fuel pellet, neutrons, moderator, fission, the balanced equation, capture, control rods, and the power loop.

Open it here (after GitHub Pages finishes, about a minute):

https://jonathanravid.github.io/core-reactor-guide/

Or download this repository and open `index.html` through any static file server. Do not open the file directly from the desktop; the browser will block the script.
